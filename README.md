# SpaceKeeper

## Descrição do Projeto

O **SpaceKeeper** é um protótipo funcional desenvolvido em Flutter para a Global Solution com o tema **Indústria Espacial**.

A proposta do aplicativo é simular uma plataforma de monitoramento ambiental baseada em dados orbitais. O app acompanha regiões estratégicas da Terra utilizando dados simulados de satélites, permitindo visualizar riscos ambientais, condições climáticas e alertas preventivos.

O projeto conecta o uso da tecnologia espacial com problemas reais da sociedade, como mudanças climáticas, queimadas, seca, monitoramento costeiro e preservação ambiental.

---

## Objetivo do Aplicativo

O objetivo do SpaceKeeper é apresentar uma solução mobile simples e funcional para:

- Monitorar regiões estratégicas do planeta;
- Exibir dados simulados de satélites;
- Identificar riscos ambientais;
- Apresentar alertas orbitais;
- Permitir que o usuário favorite regiões de interesse;
- Demonstrar como dados espaciais podem apoiar decisões preventivas na Terra.

---

## Tema da Global Solution

O projeto está relacionado ao tema **Indústria Espacial**, utilizando o conceito de dados de satélite para gerar impacto positivo na sociedade.

A aplicação se conecta principalmente aos seguintes pontos:

- Monitoramento climático;
- Prevenção de desastres naturais;
- Análise ambiental;
- Uso de dados orbitais;
- Sustentabilidade;
- Apoio à tomada de decisão.

---

## Funcionalidades Implementadas

O aplicativo possui as seguintes funcionalidades:

- Tela de Splash com identidade visual do app;
- Tela de Introdução explicando a proposta do SpaceKeeper;
- Tela principal com lista de regiões monitoradas;
- Tela de detalhes de cada região;
- Tela de alertas orbitais;
- Tela de regiões favoritas;
- Tela sobre o projeto;
- Navegação funcional entre telas;
- Lista mockada de dados;
- Cards para organização visual;
- Interação com o usuário por meio de favoritos.
